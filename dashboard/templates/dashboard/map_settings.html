Which map to use

Google Maps API key

Kept even while the free map is selected, so switching back does not mean pasting it again. Empty the box to remove it.

Enable these three APIs on the key

  • Maps JavaScript API — the maps on this dashboard
  • Map Tiles API — the map in the customer app
  • Geocoding API — turning a dropped pin into an address

Each is switched on separately in Google Cloud, and a key with only some of them enabled is the usual reason part of this works and part does not. Saving below reports on each one.

Restrict this key in Google Cloud

A map key is read by the browser and by the phone, so it can always be seen — that is true of every map on the web, not only this one. What stops somebody else spending it is the restriction, and for this key that means two settings in particular.

  • Application restrictions: None. Not a mistake. The key is called from four places: this dashboard, the customer web app on its own domain, the phone apps, which send no referrer at all, and this server. Google allows only one kind of application restriction per key, so an HTTP referrer rule would break three of those four.
  • API restrictions: the three APIs above, and nothing else. This is what stops a copied key being spent on other Google products.

Then set a daily quota cap under Google Maps Platform → Quotas and a budget alert under Billing. The cap is the real ceiling: tiles default to 15,000 requests a day, which runs out long before the monthly free allowance does.
